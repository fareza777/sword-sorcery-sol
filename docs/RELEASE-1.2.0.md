Sunward Oath 1.2.0 implements the ten gameplay and visual improvements, with larger default text throughout the mobile interface.

- Tap objects inside investigation illustrations; show/hide markers or use the named controls.
- Connect five pairs of evidence and use inventory items where they matter.
- Choose four tactical stances, read enemy movements, counter second-phase feints and prepare peaceful finishes.
- See persistent changes to the market, shrine and river; earlier help can bring witnesses to the palace.
- Choose whether to return goblin tools immediately or preserve sealed proof, and whether to return the original trade record.
- Fight in four distinct illustrated arenas.
- Consistent character models now have additional emotional poses and subtle voice-driven mouth, hair, cloak and hand motion.
- Generated environmental props animate water, a wheel, birds, leaves and river lanterns. Motion can be disabled.
- Locations retain distinct woodland, river-clan, royal-court and sun-ward identities.
- Generated inventory icons, loot notices and two visible, optional equipment rewards.

Includes six chapters, 137 story beats, twelve side quests, twelve encounters, seven endings, 108 generated art assets, 282 bundled English voice tracks, complete English/Indonesian text and three original offline scores. Dialogue and choices paginate; optional reference sheets can scroll. Whole scene images remain visible without cropping.

Autosaves now commit directly to Android's private storage before an action completes, preserving the latest choice even when the app is force-stopped immediately.

Install **sunward-oath-1.2.0.apk** to update the earlier development/primary APK with its save intact. Saves from 1.0 and 1.1 migrate automatically. The separate **-release.apk** uses the protected release signing identity; use it to update an earlier protected-signing installation, or for a fresh install. Both distributed APKs disable debugging. Android 7.0+.

The complete source ZIP includes generated art, offline audio, Gradle wrapper, build/generation tools, prompts, tests and documentation. Speech credentials and signing keys are excluded. SHA256SUMS.txt covers all three artifacts.
