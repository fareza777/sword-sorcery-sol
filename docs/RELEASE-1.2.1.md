Sunward Oath 1.2.1 improves environmental motion, battle clarity and the phone inventory.

- Removed the repeating decorative bird animation. Water reflections now follow the streams painted in each supported scene. Leaves fall occasionally, with varied timing; lanterns bob gently and the repaired wheel turns.
- Battles display the enemy's name, explicit **HP current/max**, a thicker health bar, and a separate player guard value. Round and phase remain visible.
- Added a generated two-handed sword-parry pose, painted steel sparks, a sword trail and an ornate sun-ward barrier. Attack preparation, bracing, evasion, ward projection, enemy recoil and floating damage follow the exchange timing. Each exchange completes before another move can be accepted. Winning blows briefly show zero remaining enemy HP before the story continues.
- The battle result is saved before animation, so closing the app during a finishing move retains progress. Both reduced-motion options skip the animation delay.
- Inventory actions sit beside item details. Compact tools and shorter labels preserve large type while showing more complete item cards.

Includes the complete six-chapter game, twelve side quests, seven endings, 112 generated art assets, 282 bundled English voice tracks, full English/Indonesian text and three offline scores. Existing saves remain compatible. Both distributed APKs disable debugging.

Install **sunward-oath-1.2.1.apk** to update the primary/development-signing installation. The separate **-release.apk** updates the protected-signing edition. Android 7.0+. The source ZIP includes assets, audio, build tools, tests and documentation; credentials and signing keys are excluded.

Verified with browser tests and a dedicated offline Android emulator. See docs/VALIDATION.md for scope and results.
