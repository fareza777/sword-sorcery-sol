Sunward Oath 1.3.0 adds a new illustrated app identity, two polished launch cards and a calmer offline soundscape.

- New original gold/silver sword and sun launcher icon, with emerald background, adaptive Android masks, themed icon support and all launcher densities.
- Two launch cards in order: **Sunward Oath**, then the official **F7 Developer** portrait animation supplied by the developer. Both can be skipped. Reduced motion uses a static brand card, and unavailable video cannot block startup. The complete illustrations and logo remain visible.
- Three original 64-second stereo fantasy scores with soft harp, chamber strings, flute and celesta replace the old mono tones. No crackle, waterfall or persistent environmental-noise loops.
- Sixteen designed offline SFX, including metallic sword parries, ward contact and softer UI feedback. Contact sounds follow the battle animation. Separate music/effect volume controls, smooth music fade-in, voice ducking and background silence improve listening comfort.
- Android and browser media handlers support byte ranges, giving bundled video and Ogg audio reliable duration and seeking offline.

Includes the complete six-chapter game, twelve side quests, seven endings, 112 generated story assets, 282 bundled English voice tracks and full English/Indonesian text. Saves from earlier versions remain compatible. Version code 5; Android 7.0+.

Install **sunward-oath-1.3.0.apk** to update the primary/development-signing installation. **sunward-oath-1.3.0-release.apk** updates the separate protected-signing edition. Both disable debugging. The source ZIP contains all game code, artwork, sound, branding exports, tests and build tools; API credentials and signing keys are excluded.

Tested on the computer in Chrome and a dedicated offline Android emulator. No physical phone was operated. See docs/VALIDATION.md and docs/BRANDING-AUDIO.md for details.
